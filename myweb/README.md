# Goings商城

## 项目介绍

Goings商城是一个现代化的电子商务网站前端项目，采用HTML、CSS和JavaScript构建，提供了完整的在线购物体验。网站具有响应式设计，适配各种设备屏幕尺寸，为用户提供流畅的购物体验。

## 主要功能

- **首页展示**：展示精选商品、促销活动和商品分类
- **商品分类**：包括电子产品、服装、食品、家居和美妆等多个分类
- **商品详情**：提供商品的详细信息、图片和价格，支持图片放大查看
- **专题页面**：热销商品、新品上市和优惠商品专题页面
- **购物车功能**：添加、修改和删除商品，实时计算总价
- **结算系统**：填写收货信息，选择支付方式进行结算
- **用户系统**：用户登录、注册和个人中心
- **个性化头像**：支持用户上传和显示个人头像

## 技术特点

- 纯前端实现，使用localStorage存储数据
- 模块化JavaScript代码结构
- 响应式CSS设计，适配不同屏幕尺寸
- 动态商品加载和过滤功能
- 商品图片缩放查看功能
- 用户友好的购物体验

## 页面说明

- `index.html` - 网站首页
- `product.html` - 商品详情页
- `hot.html` - 热销商品页面
- `new.html` - 新品上市页面
- `sale.html` - 优惠商品页面
- `cart.html` - 购物车页面
- `checkout.html` - 结算页面
- `login.html` - 用户登录页面
- `register.html` - 用户注册页面
- `user.html` - 用户个人中心

## 如何使用

1. 克隆或下载项目到本地
2. 使用任意现代浏览器打开`index.html`文件
3. 浏览商品，添加到购物车
4. 在购物车页面可以修改商品数量或删除商品
5. 点击"去结算"进入结算页面
6. 填写收货信息并选择支付方式
7. 提交订单完成购物流程
